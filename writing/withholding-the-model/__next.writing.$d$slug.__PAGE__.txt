21:T549,BTF splits the judgment across three tiers, and each one gets more context only when the one before it can't decide.

1. The rules engine. A one-to-one check: does this text layer match a style defined in the guidelines? Helvetica Regular at 16px for body, and so on. It returns pass or fail. Fast, cheap, deterministic.

2. The classifier. A lightweight model that asks a different question: is this style being used in the right role? It infers the role from cheap signals, like the sizes of nearby text on the page and the artboard dimensions, and returns high or low confidence.

3. The LLM. Called only when the classifier is unsure. It gets the full page as JSON: what the other text frames actually say, whether there are images, how the page is composed. It reads, rather than measures.

The principle: context should grow with ambiguity. Most layers never need more than metrics. The model is held back until a case earns it.

On the book page, that's exactly what happened. The rules engine passed, because the chapter number matched a defined style. The classifier came back with low confidence: the text sat above the body but was smaller than it. So it escalated. The LLM read the words “Chapter One”, saw the bold weight and the position, and concluded the role was correct.
